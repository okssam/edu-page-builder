# PPT 스타일 가이드

## 1. 색상 팔레트

### 메인 색상
- **Primary**: #1E3A5F (다크 네이비) - 제목, 강조
- **Secondary**: #4A90D9 (블루) - 소제목, 링크, 아이콘
- **Accent**: #F39C12 (오렌지) - 핵심 포인트, CTA
- **Background**: #FFFFFF (화이트) - 기본 배경
- **Alt Background**: #F8F9FA (라이트 그레이) - 보조 배경
- **Text Primary**: #2C3E50 - 본문 텍스트
- **Text Secondary**: #7F8C8D - 부가 설명

### 실습 슬라이드 전용
- **Practice BG**: #E8F5E9 (연초록) - 실습 배경
- **Practice Accent**: #27AE60 (그린) - 실습 강조

## 2. 폰트 규칙

### 크기 계층
- 표지 제목: 48px, bold
- 섹션 제목: 36px, bold
- 슬라이드 제목: 28px, bold
- 본문 텍스트: 20px, regular
- 부가 설명: 16px, regular
- 주석/출처: 12px, light

### 폰트 패밀리
- 한글: 'Pretendard', 'Noto Sans KR', sans-serif
- 영문: 'Inter', 'Pretendard', sans-serif
- 코드: 'JetBrains Mono', 'Fira Code', monospace

## 3. 슬라이드 크기
- 가로: 1280px
- 세로: 720px (16:9 비율)

## 4. 슬라이드 유형별 레이아웃

### 표지 슬라이드
```
┌─────────────────────────────┐
│                             │
│                             │
│      [제목 - 48px bold]     │
│      [부제목 - 24px]        │
│                             │
│      [강사명] | [날짜]       │
│                             │
└─────────────────────────────┘
```
- 배경: Primary 색상 그라데이션 또는 화이트
- 제목: 중앙 정렬

### 목차/학습목표 슬라이드
```
┌─────────────────────────────┐
│  [섹션 제목]                 │
│  ─────────────────          │
│                             │
│  1. 항목 1                  │
│  2. 항목 2                  │
│  3. 항목 3                  │
│  4. 항목 4                  │
│                             │
└─────────────────────────────┘
```
- 좌측 정렬, 번호 리스트

### 내용 슬라이드 (텍스트 + 시각요소)
```
┌──────────────┬──────────────┐
│ [제목]       │              │
│              │   [이미지/   │
│ • 포인트 1   │    다이어그램/ │
│ • 포인트 2   │    아이콘]    │
│ • 포인트 3   │              │
│              │              │
└──────────────┴──────────────┘
```
- 좌측 60%: 텍스트, 우측 40%: 시각요소
- 또는 전체 너비 사용 가능

### 실습 슬라이드
```
┌─────────────────────────────┐
│  🔧 [실습 제목]              │
│  ─────────────────          │
│  ┌───────────────────────┐  │
│  │ Step 1: 설명           │  │
│  │ Step 2: 설명           │  │
│  │ Step 3: 설명           │  │
│  └───────────────────────┘  │
│  ⏱ 예상 소요 시간: 10분      │
└─────────────────────────────┘
```
- 배경: Practice BG
- 단계별 번호, 시간 표시

### 요약/Q&A 슬라이드
```
┌─────────────────────────────┐
│                             │
│    📋 오늘 배운 내용 정리     │
│                             │
│    ✅ 핵심 포인트 1          │
│    ✅ 핵심 포인트 2          │
│    ✅ 핵심 포인트 3          │
│                             │
│    💬 Q&A                   │
└─────────────────────────────┘
```

## 5. 공통 디자인 규칙

- 슬라이드당 최대 7줄 텍스트
- 한 줄에 최대 20단어 (한글 기준 40자)
- 불릿 포인트는 최대 5개
- 여백: 상하좌우 최소 40px
- 슬라이드 번호는 우하단에 표시
- 색상 대비: WCAG AA 기준 이상 유지
- 강조는 bold 또는 accent 색상 사용 (밑줄 사용하지 않음)

```html
  </style>

    <!-- 학습 목표 -->
  </section>
  <!-- ... 본문 슬라이드들 ... -->
</body>
</html>
```
