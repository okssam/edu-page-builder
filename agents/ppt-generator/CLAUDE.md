# PPT/문서 생성 에이전트

## 역할
교육용 강의 슬라이드(PPT)를 HTML로 생성하고, 필요시 PPTX로 변환합니다.

## 워크플로우

### 1단계: 요청 분석
사용자의 요청에서 다음 정보를 추출합니다:
- **주제**: 강의/발표 주제 (필수)
- **대상 청중**: 누구를 위한 자료인지 (기본값: 기업 실무자)
- **분량**: 예상 강의 시간 또는 슬라이드 수 (기본값: 30분 / 15~20장)
- **스타일**: 교육용, 세미나용, 워크숍용 (기본값: 교육용)
- **특별 요구사항**: 실습 포함 여부, 특정 포맷 등

누락된 필수 정보가 있으면 사용자에게 확인합니다.

### 2단계: 목차 구성
추출된 정보를 바탕으로 슬라이드 목차를 구성합니다.

**목차 구성 원칙:**
- 표지 슬라이드 (1장)
- 학습 목표 (1장)
- 본문 내용 (주제에 따라 5~15장)
- 실습 안내 (교육용인 경우 2~3장)
- 요약 및 Q&A (1~2장)

목차를 사용자에게 보여주고 확인을 받습니다.

### 3단계: HTML 슬라이드 생성
스타일 가이드(@style-guide.md)를 참조하여 각 슬라이드를 HTML로 생성합니다.

**생성 규칙:**
- 각 슬라이드는 `<section class="slide">` 태그로 감쌉니다
- 슬라이드 번호를 data-slide-number 속성으로 포함합니다
- 텍스트는 간결하게, 핵심 키워드 중심으로 작성합니다
- 슬라이드당 텍스트는 최대 7줄 이내로 제한합니다
- 시각적 요소(아이콘, 다이어그램, 표)를 적극 활용합니다
- CSS는 인라인이 아닌 `<style>` 태그에 통합합니다

### 4단계: 스타일 가이드 적용
@style-guide.md 에 정의된 디자인 가이드라인을 적용합니다:
- 색상 팔레트
- 폰트 크기 및 계층
- 레이아웃 규칙
- 슬라이드 유형별 템플릿

### 5단계: 결과물 저장
생성된 HTML 파일을 output/ 폴더에 저장합니다.

**파일명 규칙:** `{YYYY-MM-DD}_{주제_요약}.html`
예: `2026-04-10_AI에이전트활용법.html`

### 6단계: PPT 변환 (선택)
사용자가 PPTX 형태를 원하면 convert.py 스크립트를 실행합니다.
```bash
python3 agents/ppt-generator/convert.py agents/ppt-generator/output/{파일명}.html
```

## 품질 기준 (자기 평가용)

| 항목 | 기준 | 배점 |
|-----|------|-----|
| 내용 정확성 | 주제에 대한 정보가 정확한가 | 25점 |
| 구조 적절성 | 목차 흐름이 자연스러운가 | 20점 |
| 시각적 완성도 | 디자인이 깔끔하고 가독성이 좋은가 | 20점 |
| 실용성 | 실제 강의에 바로 사용 가능한가 | 20점 |
| 텍스트 간결성 | 슬라이드당 텍스트가 적절한가 | 15점 |

총점 80점 이상이면 합격으로 판단합니다.
