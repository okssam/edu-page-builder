# 공통 평가 기준

## 수강생 결과물 평가 기본 프레임워크

### 평가 등급
- **S (탁월)**: 90~100점 - 실무 즉시 적용 가능, 창의적 접근
- **A (우수)**: 80~89점 - 높은 완성도, 약간의 보완만 필요
- **B (양호)**: 70~79점 - 기본 역량 달성, 추가 학습 권장
- **C (보통)**: 60~69점 - 기초 이해는 있으나 연습 필요
- **D (미흡)**: 60점 미만 - 기본 개념 재학습 필요

### 세부 평가 기준

#### 1. AI 도구 활용 능력 (30점)
| 점수 | 기준 |
|-----|------|
| 25-30 | 명확하고 구조화된 프롬프트, 맥락 설정 우수, 반복 개선 활용 |
| 18-24 | 적절한 프롬프트, 기본적인 도구 활용 |
| 10-17 | 단순 질문 수준, 프롬프트 개선 여지 많음 |
| 0-9 | 도구 사용에 어려움, 기본 조작 미숙 |

#### 2. 결과물 품질 (30점)
| 점수 | 기준 |
|-----|------|
| 25-30 | 실무에 바로 적용 가능한 수준, 디테일 완성도 높음 |
| 18-24 | 기본 요건 충족, 약간의 수정으로 실무 적용 가능 |
| 10-17 | 결과물 있으나 완성도 부족, 상당한 보완 필요 |
| 0-9 | 미완성 또는 요건 미충족 |

#### 3. 창의적 접근 (20점)
| 점수 | 기준 |
|-----|------|
| 16-20 | 독창적 활용법 제시, 다른 수강생에게 영감을 줌 |
| 11-15 | 교안 범위를 넘어선 응용 시도 |
| 6-10 | 교안 지시를 따라 수행 |
| 0-5 | 수동적 참여, 최소한의 시도 |

#### 4. 발표/커뮤니케이션 (20점)
| 점수 | 기준 |
|-----|------|
| 16-20 | 논리적 구성, 명확한 전달, 근거 제시, 질의응답 우수 |
| 11-15 | 기본적인 발표 구성, 핵심 전달 |
| 6-10 | 발표는 했으나 구성이 미흡 |
| 0-5 | 발표 미참여 또는 준비 부족 |
