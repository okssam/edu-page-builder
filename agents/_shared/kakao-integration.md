# 카카오톡 연동 가이드

## 개요
맥미니에 설치된 카카오톡 PC 앱의 **"정옥선" 대화창**을 두 가지 용도로 사용합니다:

1. **아카이빙**: 공부/강의/기억하고 싶은 내용을 올려두면 → 매일 새벽 5시에 자동 수집 → 구글 시트 카테고리별 정리
2. **명령 전달**: @자비스 로 시작하는 메시지로 에이전트에게 직접 명령

## 아카이빙 연동 구조

```
[사용자 - 하루 종일 카톡에 메모/링크 올림]
    → "정옥선" 대화창
    → [매일 새벽 5:00 AM - 오픈 클로우가 전날 내용 수집]
    → [링크 확인 + 키워드 요약]
    → [구글 시트에 카테고리별 정리]
    → [카카오톡으로 완료 보고]
```

## 명령 전달 연동 구조

```
[사용자 - @자비스 명령]
    → "정옥선" 대화창
    → [오픈 클로우 - 대화창 모니터링]
    → [Claude Code CLI 실행]
    → [결과를 "정옥선" 대화창에 입력]
```

## 맥미니 설정 방법

### 1. 카카오톡 PC 앱 설정
- 맥미니에 카카오톡 PC 앱을 설치하고 로그인합니다
- "정옥선" 대화창을 항상 열어둡니다
- 카카오톡 설정에서 화면 잠금을 해제합니다

### 2. 오픈 클로우 설정 (컴퓨터 유즈)
- 오픈 클로우를 맥미니에 설치합니다
- 다음 워크플로우를 설정합니다:

**모니터링 루프:**
```
1. 카카오톡 "정옥선" 대화창의 마지막 메시지를 읽습니다
2. 새로운 메시지가 있으면:
   a. 메시지 내용을 파싱합니다
   b. 명령어인지 일반 메시지인지 판별합니다
   c. 명령어이면 → Claude Code CLI로 전달
   d. 결과를 "정옥선" 대화창에 입력합니다
3. 5분 간격으로 반복합니다
```

### 3. 명령어 형식

카카오톡에서 에이전트에게 보내는 명령어 형식:

```
@자비스 PPT 만들어줘 - AI 활용 교육 30분
@자비스 리서치 해줘 - 최신 에이전트 트렌드
@자비스 교육 설계 - LG전자 마케팅 초급
```

`@자비스`로 시작하는 메시지를 명령어로 인식합니다.

### 4. 결과 전달 형식

```
[자비스] 요청하신 작업을 완료했습니다.

📄 PPT 생성 완료
- 파일: 2026-04-10_AI활용교육.html
- 슬라이드: 18장
- 구글 드라이브에 업로드 완료

상세 내용은 VS Code에서 확인하세요.
```

## 대안: 텔레그램 브릿지

카카오톡 직접 연동이 불안정할 경우, 텔레그램을 중간 다리로 사용할 수 있습니다:

1. 텔레그램 봇 생성 (@BotFather)
2. 맥미니에서 봇 서버 실행
3. 카카오톡 → (수동 전달) → 텔레그램 → 에이전트 실행 → 텔레그램 회신

## 참고사항
- 카카오톡은 공식 API가 없으므로 컴퓨터 유즈(화면 직접 제어) 방식을 사용합니다
- 오픈 클로우가 카카오톡 화면을 안정적으로 제어하려면 해상도와 위치를 고정해야 합니다
- 스크린샷 기반 OCR로 메시지를 읽으므로, 폰트 크기가 너무 작지 않게 설정합니다
