# 셀프 크리틱 (Self-Critique) 메타 스킬

## 개념
에이전트 시스템 전체의 구조적 모순, 비효율, 개선점을 비판적으로 검토합니다.

## 검토 항목

### 1. 구조적 완결성
- 에이전트 간 역할 중복이 있는가?
- 빠진 업무 영역이 있는가?
- 라우팅 규칙에 모순이 있는가?
- CLAUDE.md 간 참조가 올바른가?

### 2. 워크플로우 효율성
- 불필요한 단계가 있는가?
- 병렬로 처리할 수 있는 단계가 순차로 되어 있는가?
- 사용자 확인이 너무 많거나 적은가?

### 3. 하네스 품질
- 지시가 너무 모호한 부분이 있는가?
- 지시가 너무 과도하게 상세한 부분이 있는가?
- 예외 상황 처리가 되어 있는가?

### 4. 결과물 품질
- 평가 기준이 적절한가?
- 피드백 루프가 작동하는가?
- 개선 이력이 관리되고 있는가?

## 실행 방법

```
/improve-agent self-critique
```

1. [아이디어 설명] → [기대 효과]

1. ...
