# 오토 리서치 (Auto-Research) 메타 스킬

## 개념
안드레 카파시가 제안한 자기 개선 루프입니다.
AI가 스스로 결과물을 평가하고, 부족한 부분을 개선하는 과정을 반복합니다.

## 실행 프로세스

### Step 1: 현재 상태 평가
```
대상 에이전트의 최근 결과물을 가져옵니다.
해당 에이전트의 CLAUDE.md에 정의된 평가 기준을 적용합니다.
각 항목별 점수를 매깁니다.
```

### Step 2: 개선 과제 도출
```
점수가 낮은 항목을 분석합니다.
왜 점수가 낮은지 구체적 원인을 파악합니다.
개선 가능한 과제 목록을 생성합니다.
각 과제의 예상 효과를 추정합니다.
```

### Step 3: 개선 실험
```
가장 효과가 클 것으로 예상되는 과제부터 시도합니다.
에이전트의 CLAUDE.md, 스타일 가이드, 또는 워크플로우를 수정합니다.
수정된 설정으로 동일한 작업을 다시 실행합니다.
```

### Step 4: 비교 평가
```
개선 전후 결과물을 비교합니다.
동일한 평가 기준으로 점수를 매깁니다.
점수가 향상되었으면 → 변경 사항 확정
점수가 하락하거나 동일하면 → 롤백
```

### Step 5: 반복
```
Step 1~4를 N회 반복합니다 (기본값: 5회)
각 반복의 결과를 기록합니다.
최종 개선 리포트를 생성합니다.
```

## 실행 방법

```
/improve-agent [에이전트명] [반복횟수]

예: /improve-agent ppt-generator 5
```
