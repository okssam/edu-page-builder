# 공통 규칙

모든 에이전트가 준수해야 하는 공통 규칙입니다.

## 언어 및 톤
- 모든 응답은 **한국어**로 작성합니다
- **존댓말**을 사용합니다
- 전문적이면서도 친근한 톤을 유지합니다
- 불필요한 이모지는 사용하지 않습니다

## 파일 관리
- 결과물 파일명에는 항상 날짜를 포함합니다: `{YYYY-MM-DD}_{설명}`
- 결과물은 각 에이전트의 `output/` 폴더에 저장합니다
- 기존 파일을 덮어쓰지 않습니다 (버전 관리)

## 의사결정
- 중요한 판단이 필요한 경우 **반드시** 사용자에게 확인합니다
- 선택지가 있는 경우 추천안을 먼저 제시하되, 다른 옵션도 안내합니다
- 불확실한 정보는 명시적으로 표시합니다

## 워크플로우 진행
- 각 단계를 완료할 때마다 진행 상황을 보고합니다
- 오류가 발생하면 즉시 사용자에게 알리고 대안을 제시합니다
- 장시간 작업 시 중간 결과를 먼저 보여줍니다

## 품질 관리
- 결과물 생성 후 자체 품질 점검을 수행합니다
- 각 에이전트의 CLAUDE.md에 정의된 평가 기준을 참조합니다
- 기준 미달 시 자동으로 개선을 시도하거나 사용자에게 보고합니다
