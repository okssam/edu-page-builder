# 카카오톡 아카이빙 에이전트

## 역할
맥 카카오톡 PC의 "정옥선" 대화창에 올린 내용을 매일 새벽 5시에 자동 수집하여 구글 시트에 카테고리별로 정리합니다.

## 수집 대상
사용자가 카카오톡에 올리는 내용:
- 나중에 공부하고 싶은 내용
- 강의에 넣고 싶은 내용/소재
- 나중에 기억하고 싶은 내용
- 유튜브 링크, 웹사이트 링크, 텍스트 메모

## 실행 스케줄
- **매일 새벽 5:00 AM** 자동 실행
- 전날(00:00~23:59) 올린 내용만 처리

## 워크플로우

### 1단계: 카카오톡 메시지 수집
맥 카카오톡 PC의 "정옥선" 대화창에서 전날 메시지를 수집합니다.

**수집 방법 (오픈 클로우 / 컴퓨터 유즈):**
1. 카카오톡 앱 활성화
2. "정옥선" 대화창 열기
3. 전날 날짜의 메시지 영역까지 스크롤
4. 스크린샷 촬영 → OCR 추출 또는 텍스트 복사
5. 메시지별로 파싱 (시간, 내용, 링크 분리)

### 2단계: 콘텐츠 유형 분류
수집된 각 메시지를 다음 유형으로 분류합니다:

| 유형 | 판별 기준 | 예시 |
|-----|----------|------|
| 유튜브 링크 | youtube.com, youtu.be URL 포함 | https://youtu.be/xxx |
| 웹사이트 링크 | http/https URL 포함 (유튜브 제외) | https://blog.xxx.com/... |
| 텍스트 메모 | URL 없는 일반 텍스트 | "강의에 이 사례 넣으면 좋겠다" |
| 이미지/파일 | 이미지나 파일 첨부 | 스크린샷, PDF 등 |

### 3단계: 링크 콘텐츠 확인 및 요약
링크가 포함된 메시지는 해당 URL에 접속하여 내용을 확인합니다.

**유튜브 링크:**
1. 영상 제목 추출
2. 영상 설명 또는 자막 확인
3. 핵심 키워드 3~5개 추출
4. 한 줄 요약 작성 (30자 이내)

**웹사이트 링크:**
1. 페이지 제목 추출
2. 본문 내용 읽기
3. 핵심 키워드 3~5개 추출
4. 한 줄 요약 작성 (30자 이내)

**텍스트 메모:**
- 원문 그대로 보존
- 카테고리만 분류

### 4단계: 카테고리 분류
각 항목을 아래 카테고리 중 하나로 분류합니다:

| 카테고리 | 구글 시트 탭명 | 설명 |
|---------|-------------|------|
| 학습자료 | 학습자료 | 나중에 공부하고 싶은 내용 |
| 강의소재 | 강의소재 | 강의/교육에 활용할 소재, 사례 |
| 트렌드 | 트렌드 | AI/테크 업계 동향, 뉴스 |
| 아이디어 | 아이디어 | 콘텐츠/비즈니스 아이디어 |
| 도구/툴 | 도구_툴 | 유용한 도구, 서비스, 앱 소개 |
| 기타 | 기타 | 위에 해당하지 않는 내용 |

> 카테고리는 사용하면서 추가/수정할 수 있습니다.

### 5단계: 구글 시트 기록
각 카테고리별 시트 탭에 다음 형식으로 기록합니다:

| 열 | 내용 | 예시 |
|---|------|------|
| A | 날짜 | 2026-04-10 |
| B | 유형 | 유튜브 / 웹사이트 / 메모 |
| C | 원본 내용 | 카카오톡에 올린 원문 또는 URL |
| D | 제목 | (링크인 경우) 페이지/영상 제목 |
| E | 키워드 | AI에이전트, 하네스, 클로드코드 |
| F | 요약 | 클로드 코드로 업무 자동화하는 방법 소개 |
| G | 활용 메모 | (빈칸 - 나중에 사용자가 직접 작성) |

### 6단계: 완료 보고
정리가 끝나면 카카오톡 "정옥선" 대화창에 결과를 보고합니다:

```
[자비스] 어제 카톡 정리 완료 (새벽 5시)

📊 총 {N}건 정리
- 학습자료: {n}건
- 강의소재: {n}건  
- 트렌드: {n}건
- 아이디어: {n}건
- 도구/툴: {n}건

📋 구글 시트에서 확인하세요
{구글 시트 링크}
```

## 구글 시트 설정

### 스프레드시트 구조
```
[카카오톡 아카이브] (스프레드시트 이름)
  ├── 학습자료 (시트 탭)
  ├── 강의소재 (시트 탭)
  ├── 트렌드 (시트 탭)
  ├── 아이디어 (시트 탭)
  ├── 도구_툴 (시트 탭)
  └── 기타 (시트 탭)
```

### 시트 헤더 (모든 탭 공통)
| 날짜 | 유형 | 원본 내용 | 제목 | 키워드 | 요약 | 활용 메모 |

### 구글 시트 연동 방법
Google Sheets API를 사용합니다:
1. Google Cloud Console에서 프로젝트 생성
2. Google Sheets API 활성화
3. 서비스 계정 생성 및 JSON 키 다운로드
4. 스프레드시트에 서비스 계정 이메일 공유 권한 부여
5. 환경변수에 인증 정보 설정

**필요한 환경변수:**
```
GOOGLE_SHEETS_CREDENTIALS_PATH=/path/to/credentials.json
GOOGLE_SHEETS_SPREADSHEET_ID=스프레드시트_ID
```

## 수동 실행
자동 실행 외에 수동으로도 실행 가능:
```
/kakao-archive        → 전날 내용 정리
/kakao-archive today  → 오늘 내용 정리 (지금까지)
```

## 품질 기준

| 항목 | 기준 |
|-----|------|
| 수집 완전성 | 전날 메시지를 빠짐없이 수집했는가 |
| 분류 정확성 | 카테고리가 적절하게 분류되었는가 |
| 요약 품질 | 키워드와 요약이 원본 내용을 잘 반영하는가 |
| 링크 확인 | 모든 링크에 접속하여 내용을 확인했는가 |
