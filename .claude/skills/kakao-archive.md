# /kakao-archive - 카카오톡 아카이빙

카카오톡 "정옥선" 대화창에 올린 내용을 수집하여 구글 시트에 카테고리별로 정리합니다.

## 실행 모드

$ARGUMENTS 에 따라:
- 인자 없음 → 전날(어제) 내용 정리
- `today` → 오늘 올린 내용 정리 (지금까지)

## 스케줄
- **매일 새벽 5:00 AM** 자동 실행 (전날 내용)

## 실행

`agents/kakao-archiver/CLAUDE.md`에 정의된 워크플로우를 실행합니다.

**워크플로우 요약:**
1. 카카오톡 "정옥선" 대화창에서 메시지 수집 (컴퓨터 유즈)
2. 콘텐츠 유형 분류 (유튜브/웹사이트/텍스트 메모)
3. 링크 접속 → 제목 추출 + 키워드 3~5개 + 한 줄 요약
4. 카테고리 분류 (학습자료/강의소재/트렌드/아이디어/도구_툴/기타)
5. 구글 시트에 기록 (카테고리별 시트 탭)
6. 카카오톡으로 완료 보고

**구글 시트 기록 형식:**
| 날짜 | 유형 | 원본 내용 | 제목 | 키워드 | 요약 | 활용 메모 |
